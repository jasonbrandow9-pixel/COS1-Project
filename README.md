# COS1 Project & Portfolio

Repo for my Project & Portfolio 1 class work. Using it to practice Git, Visual Studio, and building a small C++ project over the term.

## Virus Spread Lab

The main project is in `dev/COS1-Console`. It's a console sim that shows how an infection can spread across a small grid. You pick a profile, set some starting cases, run it for a number of days, and watch the daily numbers and the grid.

It's only meant as a classroom model. Nothing in it is medical advice or a real prediction.

## How to build

1. Open `dev/COS1-Project.sln` in Visual Studio
2. Debug + x64
3. Build Solution
4. Start Without Debugging

More notes are in `dev/COS1-Console/README.md`.

# Portfolio Reflection Draft

## Project selection

I chose Virus Spread Lab because it gives me a way to practice C++ while seeing the effect of the rules I write. The grid, daily counts, and profile comparison make the program's behavior easier to follow. The project shows how I am learning to split responsibilities across classes and build a complete console workflow.

## Skills and technologies

I am most proud of the C++ class structure, input validation, and the use of repeatable seeds. I also used Visual Studio, Git, GitHub, and Markdown to organize the work and record each milestone.

## Challenges

One challenge was a scope error in the replay flow: settings were used outside the loop where they were created. I moved the related steps into the correct scope and changed numeric input to line-based validation with std::getline and std::stoi. I documented the fix and reviewed the simulation flow after the changes.

For the portfolio, I needed to make the project understandable to someone who cannot run a C++ console program in a browser. I added a browser preview of the same simplified rules and made clear that it is separate from the original program.

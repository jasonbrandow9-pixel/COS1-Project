# Portfolio Website

This repository's portfolio page presents the Virus Spread Lab project and links to its source, milestones, and build instructions.

## Site files

- [index.html](../index.html) contains the page content.
- [styles.css](../styles.css) contains the responsive styling.
- Existing repository screenshots in the images folder illustrate project planning and repository progress.

The page is a static site and has no build step or runtime dependencies. To update it, edit the HTML or CSS, then commit the changes to the main branch.

## GitHub Pages

The page is designed to publish from the repository root on the main branch. In the repository's Pages settings, choose **Deploy from a branch**, select **main**, and choose **/(root)**. The expected project site address is:

https://jasonbrandow9-pixel.github.io/COS1-Project/

GitHub Pages must be enabled in repository settings before the address becomes available.

# Portfolio Website

The portfolio presents Jason Brandow's Virus Spread Lab project, the work completed during its four course milestones, a browser preview, and a resume page.

## Site files

- index.html contains the portfolio.
- styles.css contains the shared responsive styling.
- demo.html contains a browser preview of the simulation rules.
- resume.html contains a concise resume based on details already documented in the course repository.
- The screenshots are served from the public COS1-Project repository's images folder.

The browser preview follows the C++ program's 30-by-14 grid, four-direction neighbor contacts, profile settings, and recovery timing. It uses the browser's random-number generator, so results differ from the C++ program.
